# Optional native mode3/6 raster commands

Frozen runtime: `runtime/build/raster-commands-001/graphics.bin`, 61392 bytes, SHA256 `4f4d211d885560a65da97c4a5d0b6a7d34231a254e7c8181507e3f2a9aaa5328`. `build.json` alongside it records every compiler input, exact RV32 ELF map, symbols and stack frames. `report.json` here records changed source hashes and all evidence. No OTA or device operation was performed by this work.

Enable with `--raster-commands --scene-session`; the tested artifact also enables input, flash reader, external-tail reader, storage diagnostics, full-store reader and canary. All existing flags remain independent and their defaults unchanged. Fresh flag-off reader and canary binaries were compared byte-for-byte to their frozen artifacts; the copied build manifests and hashes here record that proof.

Commands are the decompressed G2 image-dispatch payloads. Mode6 replaces all600×350 packedGRAY4 pixels from exact-count RLE. Mode3 parses bbox fields in units4x2, retains frame ID as diagnostic-only data (no deduplication), and decodes into the existing raster. Mode0x83 selects the first/G2-left bbox; both encoded dimensions must match, while the unused right position is not bounds-checked, matching G2 left-lens handling. Mode0x86 ignores the highbit. Identity adds modes3/6 and `rasterLens:"first-left"`;8192-byte admission,64KiB cache and1000-tick launcher/screen lease remain unchanged.

New `mm_rle_decode_window` validates the complete parent surface and rectangle, allowing a bottom/right-edge delta without declaring nonexistent trailing padding. Existing decoder entry points remain unchanged. The command parser validates complete RLE, geometry, overflow and aliases before writes. The optional scene input guard reuses the existing core checks for context, cache metadata, vector workspace, undo workspace, texture cache and pixels before clearing reply state or taking over. Valid raster commands stop/freeze retained animation, draw, and present once. Invalid commands preserve both displayed pixels and active animation. The scene's rendered framebuffer already aliases the same native canvas, demonstrated by a delta over an animated scene preserving every pixel outside its bbox. Cached objects remain available for laterSHOW. No second canvas or extra persistent allocation was introduced.

Validation:

* HostASan/UBSan:1736 adversarial/differential cases, exact pinned TypeScript sender functions `rleEncode/pack/packBox`, exact G2 decoder, full600×350 frame, bottom-edge delta, odd/padded surfaces, highbits, malformed/overflow/alias inputs, queue release/copy, allocator failures, expiry and one presentation. Zlib is removed **offline** at the original decompression boundary; native compressed-message support is not claimed.
* Actual compiledRV32 raster runtime:4 groups, including all owned-allocation alias guards, animation continuation on malformed input, delta takeover, deferred settled replies, first/left policy, repeatedFID execution, no extra core allocations and4-byte allocator alignment. Firmware/LVGL/queue/JSON are explicit mocks.
* Actual gates:7955 cases. Retained new-address canary10groups (all100 fault boundaries), reader/diagnostics12groups and input6groups pass on this exact blob. Production strict Python clients accept emitted canary/reader/diagnostic replies. No live canary rerun occurred.
* Existing portable geometry/RLE/vector suites pass; compiler guard tests8 and aggregate scope tests8 pass. Nine aggregate stages now compile a fresh optional runtime and run all these scoped suites against it.
